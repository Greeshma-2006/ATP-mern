# User Management App

A simple full-stack User Management Application built using **React (Frontend)**, **Node.js + Express (Backend)**, and **MongoDB Atlas (Database)**.

---

## 🚀 Features

* Add new users
* View list of users
* Store user details in MongoDB
* REST API integration
* Fully deployed (Frontend + Backend)

---

## 🛠️ Tech Stack

**Frontend:**

* React.js
* Tailwind CSS
* Axios

**Backend:**

* Node.js
* Express.js

**Database:**

* MongoDB Atlas

**Deployment:**

* Frontend: Vercel
* Backend: Render
